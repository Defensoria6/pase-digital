¿Cómo funciona?

1. Poné datos.json en la misma carpeta que operadores-local.html, empleados-local.html y secretarios-local.html.

2. Si servís la carpeta por HTTP (Live Server / python -m http.server), el JSON se lee automáticamente y los cambios se sincronizan entre las tres apps.

3. Si abrís con doble clic (file://), cada archivo mantiene su propio localStorage — usá Exportar / Recargar para transferir datos.
