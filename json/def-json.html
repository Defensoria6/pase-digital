¿Cómo funciona?

1. Al abrir, se intenta leer datos.json automáticamente si usa un servidor local (Live Server, python -m http.server).

2. Si abrió el archivo con doble clic (file://), seleccione el JSON manualmente con el recuadro de arriba.

3. Los cambios se guardan en el navegador. Use el botón Exportar JSON del panel para descargar una copia actualizada.
